Ready Room

five tabs that cover the whole gaming session — before, during, after
Session — screen, notifications, night light, power: borrowed and returned
Pads — controllers, live input, rumble test
Gear — battery levels for mice, keyboards, headsets
Clips — replay buffer, save the last 60 s
Overlay — system metrics above the game, MangoHud sync
